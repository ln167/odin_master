Parametric surfaces (NURBS / B-spline)

What it is

A smooth skin defined by a few control points; the curve is a formula you can evaluate at any density. It is a boundary only, not a filled volume like goo: nothing is stored inside.

Controls

Drag the white control points. Click empty space to ask "what's inside?".

Live stats

Good at

  • Tiny data, smooth at any zoom
  • Designed / carved art and architecture

Bad at

  • Topology changes and arbitrary damage
  • No interior; booleans need trim curves

In 3D / for our game: use for hand-designed columns and statues, not for rock that gets quarried.
