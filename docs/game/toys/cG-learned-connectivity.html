G - Learned connectivity

What it is

Blocks form a load graph (each block is a node, touching blocks are edges); an exact solver decides which blocks fall after you knock some out (cut off from the ground, or crushed by too much load). A tiny graph neural network (GNN: each node repeatedly mixes its state with its neighbours' through one shared small neural net) is trained to guess the same answer. After K rounds of mixing a node only "knows" about blocks K hops away, so far-away causes are invisible to it.

Controls

Click blocks to remove/restore. Hover a block to see its K-hop view. Left = exact, right = GNN; magenta outline = GNN wrong.

Live stats

Good at

  • Fixed cost per node per round; every node in parallel (GPU-friendly).
  • Can learn shortcuts (e.g. "block over a hole falls") without solving anything.
  • Model is tiny: a few hundred numbers, independent of world size.

Bad at

  • Wrong answers with no guarantee, including missed falls.
  • Blind beyond K hops: a removed arch foot far away is invisible.
  • Needs the exact solver anyway, to make its training labels.

In 3D / for our game: same graph in 3D; usable only as a cheap first guess that the exact pass confirms, never as the authority.

Prior art: GNN crack propagation (Perera et al. 2022), DeepFracture (2025), GNN block-stack stability (2024); none in shipped games.
