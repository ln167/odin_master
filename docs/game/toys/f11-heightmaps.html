Height maps: single and layered

What it is

A height map stores one number per ground column: how high the solid top is. Layered (2.5D) stores a short list of spans per column, each span being (material, top, bottom), so air gaps can exist inside a column.

Controls

Brush: size

Live stats

Good at

  • Very cheap, about 1000x less than voxels
  • Perfect for terrain and strata

Bad at

  • No arbitrary 3D carving (single map: no overhangs or caves)
  • Overhangs need layers; layers explode for sculpture

In 3D / for our game:

Use it for the big ~4 km terrain and rock strata; switch to voxels only inside carved sculpture zones.
