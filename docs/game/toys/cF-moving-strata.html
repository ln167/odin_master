Moving layered height fields

What it is

Each column of ground is a stack of layers (material + thickness), like rock strata in a road cut. Water erodes the top layer, carries sediment sideways and drops it as a new thin layer, so the strata keep changing. Mass is only ever moved, never created.

Controls

Drag on the canvas to use the brush.

Live stats

Good at

  • Cheap, geology-true strata that evolve
  • Mass conservation is easy to check

Bad at

  • Still 2.5D: no true overhangs or caves
  • Layer count grows unless merged

In 3D / for our game:

A 2D grid of columns, each a short layer list; quarry digs pop top spans and haul them into inventory.
