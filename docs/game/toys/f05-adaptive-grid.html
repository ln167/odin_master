Adaptive grid (quadtree)

What it is

A grid whose cells split into 4 smaller cells only where the rock's surface passes through them. Big cells stay big in solid or empty areas, so memory follows the surface, not the area.

Controls

drag on canvas to carve; hover to trace a lookup

Live stats

Lookup path (hover)

move the mouse over the rock

Good at

  • Memory grows with surface, not volume.
  • Multi-resolution: coarse far away, fine up close.
  • Skips empty/solid space in one step.

Bad at

  • Neighbour lookup means walking the tree.
  • Edits re-subdivide or merge cells.
  • More complex code than a flat array.

In 3D / for our game:

Octree / sparse voxel octree / VDB / voxel DAG: store a quarry-sized mountain at fine detail only at its surface, and dedupe repeated rock chunks.
