Tetrahedral mesh (2D: triangles)

What it is

The rock's inside is filled with small elements (tetrahedra in 3D, triangles here), the way engineers mesh a part for finite-element (FEM) simulation. Each element carries its own data (material, damage), and the shared faces between elements are where cracks can run.

Controls

Click the rock to strike it.

2D bytes = verts × 8 + tris × (12 idx + 1 material + 4 damage).
3D bytes = verts × 12 + tets × (16 + 5).

Materials: soft sandstone, granite, hard flint. A bond (shared edge) breaks when both triangles beside it are over 50% damaged.

Good at

  • Interior data per element (material, damage, stress).
  • Cracks along element faces; exact-ish shape with few elements.

Bad at

  • Cracks limited to element faces: jaggy unless refined.
  • Building and refining tet meshes is hard.

In 3D / for our game

Great for a few hero rocks that must break believably; too costly to mesh and refine for a whole mountain.
