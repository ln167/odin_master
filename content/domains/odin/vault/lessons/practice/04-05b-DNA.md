# DNA Strand

**Concepts:** fixed arrays · enums · bit-sets · for loops
**Time:** ~20–30 min · **Output:** terminal

The four DNA bases are A, C, G, T. Put a strand of them in a fixed array, loop over it, and use a bit-set to mark the purines (A and G) — then check whether a given base is one, and count how many the strand holds.

Reach for an enum, a fixed array, a for loop, and a bit-set — plus whatever else you need.

Print something like:

```
20
A
G
T
true
false
9
```

Stretch: build the complement strand (A<->T, C<->G), or add a pyrimidine bit-set and report GC-content.
